```
data/raw/
├── R1, R2, R3, R4, R5, R6/   # 病床機能報告 (年度別, 様式1/様式2)

├── patient_survey_2023/      # 患者調査 令和5年

└── population_2025.xlsx      # 同上 (2025年版)
```

## 2. データソース詳細リファレンス

### 2-A. 厚生労働省系

#### 2-A-1. 病床機能報告

- **概要**: 各医療機関が病棟単位で、構造・機能・実績を毎年 MHLW に提出・公開するオープンデータ
- **公開URL**: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000055891.html
- **形式**: Excel (地方ブロック別に分割)
- **粒度**: 病院 × 病棟 × 年度
- **年度カバレッジ**: 令和元年 (R1, 2019) 〜 令和6年 (R6, 2024)
- **ライセンス**: 政府標準利用規約 (CC-BY 4.0相当)
- **構成**:
  - **様式1**: 病院・病棟の構造情報 (R6版で約772列)
    - 医療機関基本情報 (名称・コード・二次医療圏・構想区域)
    - 病棟コード・名称・病床種別・算定入院料
    - **現在の病床機能・将来(6年後)の病床機能**
    - 一般病床／療養病床の許可病床数・最大使用病床数
    - **職員数** (常勤/非常勤、11職種: 看護師・准看護師・看護補助者・助産師・理学療法士・作業療法士・言語聴覚士・薬剤師・臨床工学技士・管理栄養士・救急救命士)
    - **年間新規入棟患者数 (月次12ヶ月分)**
    - **年間在棟患者延べ数 (月次)**
    - **年間退棟患者数 (月次)**
    - 入棟前/退棟先の場所別患者数
    - 退院後在宅医療の状況
    - 分娩件数
    - 重症度・医療看護必要度
  - **様式2**: 診療実績 (R6版で約210列)
    - 入院基本料・特定入院料の算定状況 (67項目)
    - 手術の実施状況 (30項目)
    - がん・脳卒中・心筋梗塞等の治療状況 (19項目)
    - 重症患者対応状況 (14項目)
    - 救急医療の実施状況 (19項目)
    - 在宅復帰支援状況 (13項目)
    - 全身管理の状況 (8項目)
    - リハビリテーション実施状況 (15項目)
    - 長期療養患者の受入 (3項目)
    - 医科歯科連携状況 (4項目)
- **URLパターン**:
  - R6: `https://www.mhlw.go.jp/content/10800000/001299892.xlsx` (北海道・東北) 等
  - 各年度・地方ブロック別に個別URL → `scripts/download.py` の `DOWNLOADS` 参照
- **ダッシュボードでの利用**: ✅ 全面的に利用
  - 病院カルテ (基本情報・病床機能・職員・年間入院実績・診療実績)
  - 構想区域分析
  - 全国俯瞰マップ
  - 経年トレンド

#### 2-A-2. 医師・歯科医師・薬剤師統計

- **概要**: 全国の医師・歯科医師・薬剤師の就業場所・年齢・診療科分布の隔年統計
- **公開URL**: https://www.mhlw.go.jp/toukei/saikin/hw/ishi/22/index.html
- **形式**: Excel (R04_DL-hyo.xlsx / R04_DL-toukeihyo.xlsx 等)
- **粒度**: 都道府県・指定都市・中核市
- **最新版**: 令和4年 (2022年末)、隔年更新
- **ライセンス**: 政府標準利用規約
- **主要フィールド** (本ダッシュボード取込分):
  - 都道府県別 医師総数 / 医療施設従事医師数 (+男女別)
  - 都道府県別 歯科医師総数 / 医療施設従事歯科医師数
  - 都道府県別 薬剤師総数 / 薬局・医療施設従事薬剤師数
  - **人口10万対** 各指標
- **拡張の余地** (未取込):
  - 診療科別 医師数 (小児科・産婦人科・精神科等)
  - 年齢階級別分布
  - 二次医療圏別 (21表)
- **ダッシュボードでの利用**: ✅ 地域ダッシュボード「医療・介護リソース」

#### 2-A-3. 医療施設 (静態・動態) 調査・病院報告

- **概要**: 全国の医療施設 (病院・一般診療所・歯科診療所) の開設状況・構造・診療科目の年次統計 + 病院の毎月の患者数
- **公開URL**: https://www.mhlw.go.jp/toukei/saikin/hw/iryosd/23/
- **形式**: Excel (統計表編・概況編別)
- **粒度**: 都道府県・指定都市・中核市 (集計)、病床規模別
- **最新版**: 令和5年 (2023年10月1日現在)
- **ライセンス**: 政府標準利用規約
- **主要内容**:
  - 都道府県別 病院数・精神科病院数・一般病院数・一般診療所数・歯科診療所数・有床診療所数 (+人口10万対)
  - 病院報告: 1日平均入院/外来患者数、病床利用率、平均在院日数 (**都道府県別集計のみ**、個別病院データは非公開)
- **拡張の余地**:
  - 病床規模別の詳細分布
  - 開設主体別 (国・公的・医療法人・個人等)
- **ダッシュボードでの利用**: ✅ 地域ダッシュボード「医療・介護リソース」の施設数 / 経年トレンドの利用率

#### 2-A-4. 患者調査

- **概要**: 3年毎の調査。全国の医療施設に対して調査日現在の患者数・傷病構造を全数/標本調査
- **公開URL**: https://www.mhlw.go.jp/toukei/saikin/hw/kanja/23/index.html
- **形式**: Excel (hyo.xlsx / toukei.xlsx / sankou.xlsx)
- **粒度**: 全国、都道府県別、傷病分類別、年齢階級別、性別
- **最新版**: 令和5年 (2023年10月)
- **ライセンス**: 政府標準利用規約
- **主要内容**:
  - **受療率 (人口10万対)** × 年齢階級別 × 入院/外来
    - 令和5年 入院受療率: 0-14歳=164, 15-34歳=171, 35-64歳=450, 65歳以上=2449, 75歳以上=3351
  - 傷病大分類別 受療率 (循環器系、新生物、精神及び行動の障害 等)
  - 傷病分類 × 年齢階級別 推計患者数
- **ダッシュボードでの利用**: ✅ 「将来患者数推計」の受療率データ

#### 2-A-5. 介護サービス施設・事業所調査

- **概要**: 全国の介護保険施設・居宅サービス事業所の施設数・定員・従事者数の年次統計
- **公開URL**: https://www.mhlw.go.jp/toukei/saikin/hw/kaigo/service23/index.html (概況) / https://www.e-stat.go.jp/stat-search/files?tstat=000001029805 (詳細表)
- **形式**: Excel (概況) / CSV (Shift-JIS、e-Stat 詳細表)
- **粒度**: 全国、都道府県、サービス種別
- **最新版**: 令和5年 (2023年10月1日現在)
- **ライセンス**: 政府標準利用規約
- **主要内容** (本ダッシュボード取込分):
  - 介護老人福祉施設 (特養) 都道府県別施設数・定員・従事者数
  - 介護老人保健施設 (老健) 都道府県別施設数・従事者数
  - 介護医療院 都道府県別施設数
- **拡張の余地**:
  - 居宅サービス事業所 (訪問介護・通所介護 等)
  - 地域密着型サービス
  - 介護職員の職種別 (介護福祉士・PT・OT・ST・社会福祉士 等)
- **ダッシュボードでの利用**: ✅ 地域ダッシュボード「介護保険施設」

#### 2-A-6. 精神保健福祉資料 (630調査)

- **概要**: 全国の精神科病院の施設・患者構造の年次調査 (毎年6月30日時点)
- **公開URL**: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/hukushi_kaigo/shougaishahukushi/toukei/630.html (情報ポータル)
- **形式**: Excel (複数シート、都道府県別配置)
- **粒度**: 全国、都道府県
- **最新版**: 令和7年度 (令和6年度630調査)
- **ライセンス**: 厚労省公開
- **主要内容**:
  - 都道府県別 精神科病院数・精神病床数
  - 入院形態別 在院患者数 (任意・医療保護・措置・その他)
  - 開放/閉鎖病棟の別
  - 疾患分類別 (F0認知症 / F1物質 / F2統合失調症 / F3気分障害 / F4神経症 / F5生理 / F6人格 / F7知的 / F8発達 / F9小児期 / てんかん / その他)
  - 在院期間別 (3ヶ月未満 / 3-12ヶ月 / 1年以上) × 65歳以上/未満
  - 職員数 (精神科医・指定医・看護師・PSW・臨床心理・OT・PT 等)
  - 医療保護入院・措置入院の患者数
- **ダッシュボードでの利用**: ✅ 地域ダッシュボード「精神科医療」タブ

#### 2-A-7. 医療機能情報提供制度 (医療情報ネット)

- **概要**: 各医療機関の基本情報・診療科・診療時間等の全国統一データベース (2024-04 統一化)
- **公開URL**: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryou/newpage_43373.html
- **形式**: CSV (UTF-8 BOM)、ZIP 配布
- **粒度**: 全医療機関 (病院・診療所・歯科診療所・薬局・助産所)
- **最新版**: 2025-12-01 (半年毎更新)
- **ライセンス**: 政府標準利用規約
- **主要内容** (公開分):
  - 施設基本情報 (名称・住所・座標・URL)
  - 診療科目・診療時間
  - 病床種別 (一般・療養・精神・結核・感染症)
  - 機関区分
- **公開されていないデータ** (各県公表分には含まれるが中央集約版には無い):
  - 年間外来患者数
  - 年間新規入院患者数
  - 対応可能な疾患・治療
- **ダッシュボードでの利用**: ✅ 精神科病院の住所・座標取得 (病床機能報告に含まれない精神科専門病院用)

#### 2-A-8. DPC退院患者調査

- **概要**: DPC/PDPS 参加病院 (約1,700) の退院患者データ

- **形式**: Excel (参考資料1〜3、複数ファイル)
- **粒度**: 病院 × MDC (診断群) × 処置
- **最新版**: 令和5年度 (令和4年4月〜令和5年3月退院患者)
- **ライセンス**: 厚労省公開
- **主要内容**:
  - 病院別 退院患者数
  - 病院別 平均在院日数 (MDC別)
  - 診断群分類別 件数 (病院 × 診断群)
  - 予定/救急入院別
  - 手術・処置有無別
  - 再入院・再転棟状況
- **対象病院**: DPC対象病院のみ (~1,700病院、全病院の約20-25%)
- **カバーされないデータ**: 外来患者数、DPC非対象病院
- **ダッシュボードでの利用**: ❌ 未取込 (拡張候補)

### 2-B. 国立社会保障・人口問題研究所 (IPSS)

#### 2-B-1. 日本の地域別将来推計人口 (令和5年推計)

- **概要**: 市区町村・都道府県別の将来人口推計 (2020→2050、5年刻み)
- **公開URL**: https://www.ipss.go.jp/pp-shicyoson/j/shicyoson23/t-page.asp
- **形式**: Excel (kekkahyo1-4 / suikei_kekka / 参考表)
- **粒度**:
  - 都道府県・市区町村・政令市の区
  - 5歳階級別 (0-4歳, 5-9歳, ..., 95歳以上)
  - 性別 (男女)
  - 年次: 2020, 2025, 2030, 2035, 2040, 2045, 2050
- **ライセンス**: IPSS 公開 (出典明記で利用可)
- **主要内容**:
  - 総人口
  - 年齢3区分別人口 (0-14歳, 15-64歳, 65歳以上)
  - 75歳以上 (再掲)
  - 人口指数 (2020=100)
  - 5歳階級別×男女別 推計人口
- **本ダッシュボードでの使用ファイル**:
  - kekkahyo1.xlsx: 総人口

## 4. 計算指標 (派生データ) の定義

ダッシュボードで独自計算している指標の定義と出典。

### 4-1. JMAP 医療介護需要予測指数

- **出典**: 日本医師会 JMAP (https://jmap.jp/) 方式
- **計算**:
  - 医療需要 = 0-14歳×0.6 + 15-39歳×0.4 + 40-64歳×1.0 + 65-74歳×2.3 + 75歳以上×3.9
  - 介護需要 = 40-64歳×1.0 + 65-74歳×9.7 + 75歳以上×87.3
  - 指数 = 各年の需要値 / 2020年の需要値 × 100
- **入力**: IPSS 5歳階級別推計人口 (suikei_kekka.xlsx)
- **出力**: `jmap_index.json`
- **粒度**: 全国、47都道府県、361構想区域

### 4-2. 将来患者数推計

- **出典**: IPSS × 患者調査 の掛け合わせ (本プロジェクト独自実装)
- **計算**:
  - 年齢階級別 推計人口 × 年齢階級別 受療率 (人口10万対) / 100,000
  - 入院 / 外来 それぞれで、疾病分類別 (全体 / 精神 / 循環器 / 新生物 / 呼吸器 / 筋骨格系) に算出
  - 65-74歳の受療率は 65歳以上 から 75歳以上 を差し引いて導出
  - 15-64歳の受療率は 15-34歳と35-64歳の人口加重平均
- **入力**: `population_future.json` + `utilization_rates.json`
- **出力**: `src/lib/patient-forecast.ts` の `forecastPatients()`
- **粒度**: 全国、都道府県、構想区域

### 4-3. 人口10万対指標

- **出典**: 本プロジェクト独自 (JMAP等の慣行に従う)
- **計算**: 各メトリクス値 / 総人口 × 100,000
- **対象メトリクス**: 医師数、歯科医師数、薬剤師数、病院数、診療所数、歯科診療所数、病床数

### 4-4. 75歳以上1千人対指標

- **用途**: 介護需要対応量の評価
- **計算**: 介護保険施設数 / (75歳以上人口 / 1,000)

### 4-5. 平均在院日数 (病院カルテ)

- **計算**: 年間在棟患者延べ数 / 年間新規入棟患者数
- **入力**: 病床機能報告 様式1
- **注意**: 様式1ベースの概算。病院報告の公式な平均在院日数とは計算方法が異なる

### 4-6. 病床利用率 (病院カルテ)

- **計算**: 年間在棟患者延べ数 / (最大稼働病床数 × 365) × 100
- **入力**: 病床機能報告 様式1

## 5. データの制約と注意事項

### 5-1. 粒度の制約

- **病院報告**: 外来患者延べ数は**都道府県・病床規模別集計のみ公開**、個別病院は非公開
- **NDBオープンデータ**: 病院単位ではなく地域別集計のみ
- **介護サービス施設・事業所調査**: 構想区域レベル分解は未実装 (都道府県単位まで)

### 5-2. 年度整合性

- 各データソースで調査時点が異なる
  - 病床機能報告: 各年度 (4月〜翌3月)
  - 医師統計: 隔年 (令和4年=2022年末)
  - 医療施設調査: 毎年10月1日
  - 患者調査: 3年毎 (令和5年=2023年10月)
  - 介護サービス調査: 毎年10月1日
  - IPSS: 5年毎推計 (令和5年推計)
  - 人口: 国勢調査ベース (2020年) / 住民基本台帳 (毎年)
- 計算指標は**混在**しているため、厳密な年度統一はされていない (最新値を使用)

### 5-3. データ品質

- **病床機能報告 R4/R6 同値問題**: 一部病院で令和4年度と令和6年度の報告値が同一のケースあり (厚労省元データ由来)
- **IPSS 福島浜通り地域**: 原発避難区域13市町村は個別推計値なし (広域集計のみ)
- **病床機能報告への参加**: 精神科専門病院の一部は参加していない (630調査で補完)

### 5-4. 構想区域名の取得

- `areas/index.json` は一部の構想区域 (例: 千葉 東葛北部 1203) を欠いている
- 正の名前ソースは `hospitals/index.json` の `areaName` を使用

### 5-5. 保険医療機関コードと病床機能報告コード

- 病床機能報告の医療機関コード (10桁) = 保険医療機関コード
- 厚生局の施設基準届出データと直接joinが可能
- 精神科専門病院は P プレフィックスの独自コード (保険医療機関コードとは異なる)

## 6. 今後の拡張候補

### 6-1. 厚生局 施設基準届出受理状況

優先度: **最高**。病院経営者が最も関心の高い「加算取得状況」を完全網羅できる。

- 7厚生局 × 数MB〜20MB の ZIP (月次)
- 病院 × 1000+ 加算項目のマトリクス
- 実装コスト: 中〜大 (1-2日)
- 想定UI: 病院カルテに「施設基準届出状況」セクション + 近隣病院との比較

### 6-2. DPC退院患者調査

優先度: 中。DPC参加病院 (~1,700) に限定されるが、重要な大規模病院をカバー。

- 施設別 退院患者数・平均在院日数
- MDC別 内訳
- 実装コスト: 中

### 6-3. 病床機能報告 様式2 の未取込項目

優先度: 中。既に一部取得しているデータの拡張。

- 重症患者対応、在宅復帰支援、長期療養患者受入 等、現在未抽出の約100項目
- 実装コスト: 小 (preprocess.py にカラム追加のみ)

### 6-4. 地域密着型介護サービス・居宅サービス

優先度: 低-中。在宅医療との連携分析に有用。

- 訪問介護、通所介護、小規模多機能、看護小規模多機能
- 実装コスト: 中

### 6-5. 病院別 外来患者数の代替取得

優先度: 中-高 (ユーザーニーズが高い)。

- 都道府県レベル公開データでは取得できない
- 代替案:
  - 代理指標 (化学療法件数、放射線治療件数等) を「外来診療規模の目安」として表示
  - 有料DB (caremap, ウェルネス社) の導入

### 6-6. 診療報酬改定データの統合

優先度: 低-中。経営インパクト分析に有用。

- 令和6年度改定 点数変更
- 各加算の点数推移

### 6-7. 地域医療構想データの取込

優先度: 中。

- 都道府県の地域医療構想調整会議の公表データ
- 構想区域ごとの 2025年病床必要量 (高度急性期/急性期/回復期/慢性期)
